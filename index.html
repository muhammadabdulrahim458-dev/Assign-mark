Print / PDF Export Tips

For the cleanest PDF output in your browser print dialog:

  • Set Destination to Save as PDF.
  • Turn on Background graphics (needed for cover page, code blocks and dark themes).
  • Set Margins to Default; page size and margin come from the Layout tab.
